# Alpha Wallet Finder

Paste a Solana memecoin contract address (Pump.fun or Raydium, including Token-2022 mints) and get its top 100-500 traders ranked by realized PNL: entry/exit price, average multiple, % PNL, and $ PNL. Click a wallet to open an Axiom-style detail view (balance, PNL chart, performance breakdown, activity feed). Select individual wallets or "select all" and export them to a JSON file (named `highpnl <token>.json`) formatted for tracking-bot import.

## Status

The trader/wallet data is currently generated by a deterministic mock provider (`src/lib/mockData.ts`) so the UI is fully functional without any API keys. To go live, replace `buildTopTraders` / `buildWalletDetail` with calls to a real Solana data provider (e.g. Helius, Birdeye, Solana Tracker) inside [src/app/api/top-traders/route.ts](src/app/api/top-traders/route.ts).

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project structure

- [src/app/page.tsx](src/app/page.tsx) — CA input, limit selector (100/150/250/500), results table.
- [src/app/api/top-traders/route.ts](src/app/api/top-traders/route.ts) — API route returning token + trader data.
- [src/components/TradersTable.tsx](src/components/TradersTable.tsx) — sortable table, row selection, export buttons.
- [src/components/WalletDetailModal.tsx](src/components/WalletDetailModal.tsx) — wallet detail popup.
- [src/lib/export.ts](src/lib/export.ts) — builds the tracking-bot JSON and triggers the download.
- [src/lib/mockData.ts](src/lib/mockData.ts) — deterministic mock data provider (swap for a real API).
